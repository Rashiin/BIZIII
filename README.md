# تراز — نمونهٔ وب‌سایت سازمانی و پنل مدیریت پروژه‌های ساختمانی

نسخهٔ نمایشی (دمو) یک وب‌سایت فارسی و راست‌چین برای یک شرکت ساختمانی، به‌همراه پنل مدیریت اختصاصی با نقش‌ها و سطوح دسترسی.
نام برند «تراز»، پروژه‌ها، اشخاص و اعداد همه ساختگی هستند.

## اجرا

پروژه هیچ وابستگی و مرحلهٔ build ندارد. کافی است پوشه را با یک وب‌سرور ساده باز کنید:

```bash
python3 -m http.server 8080
# سپس: http://localhost:8080
```

برای انتشار، همین پوشه را روی GitHub Pages، Netlify یا هر هاست استاتیکی قرار دهید.

## صفحات وب‌سایت عمومی

| صفحه | توضیح |
|---|---|
| `index.html` | صفحهٔ اصلی: معرفی، پروژه‌های فعال با درصد پیشرفت، خدمات، مسیر همکاری، معرفی پورتال، نظرات |
| `projects.html` | فهرست پروژه‌ها با فیلتر وضعیت، شهر و جست‌وجو |
| `project.html#aseman` | جزئیات پروژه: گالری، مشخصات فنی، درصد پیشرفت هر مرحلهٔ اجرا، امکانات، موقعیت |
| `about.html` | دربارهٔ ما: تاریخچه، ارزش‌ها، مدیران، گواهینامه‌ها |
| `contact.html` | فرم تماس با اعتبارسنجی شمارهٔ موبایل و کد پیگیری |

تصویر هر پروژه به‌صورت خودکار و بر اساس درصد پیشرفتش رسم می‌شود: طبقات تکمیل‌شده با نما، طبقات در حال اجرا با اسکلت، و طبقات آینده خط‌چین.

## پنل مدیریت (`panel/index.html`)

رمز همهٔ حساب‌های نمایشی `demo1234` است. در صفحهٔ ورود، دکمه‌های ورود سریع هم هست.

| نام کاربری | نقش | آنچه می‌بیند |
|---|---|---|
| `ceo` | مدیرعامل / مدیر سیستم | همه‌چیز، تأیید نهایی هزینه‌های مهم، کاربران و نقش‌ها، تنظیمات |
| `pm` | مدیر پروژه | فقط پروژه‌های خودش؛ تأیید هزینه تا سقف تعیین‌شده؛ ویرایش پیشرفت |
| `finance` | کارشناس مالی | هزینه‌ها، گزارش‌گیری و خروجی CSV |
| `site` | سرپرست کارگاه | ثبت گزارش روزانه با عکس، درخواست هزینه، بارگذاری مدارک |
| `contractor` | پیمانکار | پورتال اختصاصی: قرارداد، صورت‌وضعیت‌ها، ارسال صورت‌وضعیت جدید |
| `owner` | مالک / خریدار | پورتال اختصاصی: پیشرفت واحد، برنامهٔ اقساط، گزارش‌ها، مدارک، پیام به مدیر پروژه |

از منوی کاربر (بالای صفحه) می‌توان بدون خروج، با حساب دیگری وارد شد و تفاوت دسترسی‌ها را دید.

### قابلیت‌ها

- **داشبورد مدیریتی:** شاخص‌های کلیدی، منحنی S (پیشرفت واقعی در برابر برنامه)، هزینهٔ ماهانه، هشدار عبور از بودجه، مقایسهٔ مصرف بودجه با پیشرفت فیزیکی، گزارش فعالیت‌ها (Audit log)
- **پروژه‌ها:** تعریف و ویرایش پروژه، به‌روزرسانی پیشرفت هر مرحله (پیشرفت کل به‌صورت وزنی محاسبه می‌شود)، زبانه‌های گزارش، هزینه، مدارک و ذی‌نفعان
- **گزارش روزانه:** وضعیت هوا، نیروی کار، کارهای انجام‌شده، مشکلات، برنامهٔ روز بعد و بارگذاری عکس (کشیدن و رها کردن)
- **هزینه‌ها با گردش تأیید دومرحله‌ای:** هزینه‌های تا سقف تعیین‌شده با تأیید مدیر پروژه و هزینه‌های بالاتر پس از آن با تأیید نهایی مدیرعامل پرداخت می‌شوند. رد درخواست بدون ذکر دلیل ممکن نیست و همهٔ مراحل در تاریخچهٔ درخواست ثبت می‌شود.
- **تصاویر و مدارک:** نقشه، قرارداد، مجوز، صورت‌وضعیت، صورتجلسه و آزمایش‌ها، با امکان اشتراک با مالکین
- **مشتریان، مالکین و پیمانکاران:** مبلغ قرارداد، پرداخت یا وصول، و ساخت حساب پورتال
- **گزارش‌گیری:** فیلتر بر اساس پروژه و وضعیت، تفکیک بر اساس دسته و پروژه، خروجی CSV برای اکسل
- **کاربران و نقش‌ها:** تغییر نقش، فعال یا غیرفعال کردن حساب، تعیین پروژه‌های مجاز، و ماتریس مجوزها که قابل ویرایش است
- حالت روشن و تاریک، طراحی کاملاً واکنش‌گرا برای موبایل

تغییراتی که در دمو می‌دهید در حافظهٔ مرورگر (localStorage) ذخیره می‌شود و از «تنظیمات ← بازنشانی دادهٔ نمایشی» به حالت اول برمی‌گردد.

## معماری پیشنهادی نسخهٔ اصلی

این دمو تمام منطق را در مرورگر اجرا می‌کند تا بدون سرور قابل نمایش باشد. در نسخهٔ اصلی:

- **فرانت‌اند:** Next.js با رندر سمت سرور برای صفحات عمومی (سئو)، و همین رابط کاربری برای پنل
- **بک‌اند:** Laravel یا NestJS با API مستند، پایگاه دادهٔ PostgreSQL، صف برای پیامک و پردازش تصویر
- **امنیت:** هش رمز با Argon2، ورود دومرحله‌ای پیامکی برای نقش‌های مدیریتی، قفل حساب پس از تلاش‌های ناموفق، بررسی مجوز و محدودهٔ پروژه در سرور برای هر درخواست، محافظت CSRF و محدودیت نرخ درخواست، فایل‌ها در فضای خصوصی با لینک دانلود امضاشده و زمان‌دار، پشتیبان‌گیری روزانه
- **سئو و سرعت:** متادیتا و Open Graph برای هر صفحه، داده‌های ساختاریافتهٔ Schema.org، نقشهٔ سایت، تصاویر WebP با بارگذاری تنبل، کش و CDN
- **توسعه‌پذیری:** ساختار ماژولار (پروژه، مالی، مدارک، اشخاص، کاربران) تا افزودن بخش‌هایی مثل انبار مصالح یا اپ موبایل کارگاه بدون بازنویسی ممکن باشد
